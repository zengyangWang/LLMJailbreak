你收到一个模型回复，你需要提取问题的内容并返回。逐个返回问题，每个问题用换行符分隔。模型回复是'{resp}'。

将你的输出和分析格式化为JSON：
{{
    "questions": [
        {{
            "question": 第一个问题
        }},
        {{
            "question": 第二个问题
        }},
        {{
            "question": 第三个问题
        }},
        ...
        {{
            "question": 最后一个问题
        }}
    ]
}}
